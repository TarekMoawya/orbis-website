# Orbis website

Company website for Orbis Software Solution and Technology, served at https://orbissolutionscom.org via GitHub Pages.

It is a single static page: `index.html` plus images in `assets/`.

- Add a project: copy one `<article class="project">` block in the "Our work" section, and put its screenshots in `assets/work/` (WebP, about 1600px wide).
- Preview locally: open `index.html` in a browser.
